<h1 align="center">=Добро и позитив=</h1>

<p align="center">Пишешь «Всем добра и позитива!», жмёшь Enter — уходит «=Всем добра и позитива!=».</p>

Приложение для Mac, которое стилизует сообщения под стиль Сергея Симонова времён =Добра и позитива=. Работает в Telegram, WhatsApp, Slack, Discord, браузере и везде, где сообщение отправляется по Enter.

## Установка

Нужен macOS 13 Ventura или новее.

### Способ 1. Одна команда (проще всего)

1. Открой **Терминал**: нажми `⌘ Пробел`, набери «Терминал» и нажми Enter.
2. Вставь эту строку и нажми Enter:
   ```sh
   curl -fsSL https://raw.githubusercontent.com/cybertatar/DOBROANDPOZITIV/main/install.sh | sh
   ```
3. macOS спросит про **Универсальный доступ**. Нажми «Открыть Системные настройки» и включи переключатель у **DOBROANDPOZITIV**. Пароль от Mac может понадобиться.

Готово: в строке меню наверху появился значок `=👍=`.

Та же команда обновляет приложение до свежей версии.

### Способ 2. Без Терминала

1. Скачай [DOBROANDPOZITIV.dmg](https://github.com/cybertatar/DOBROANDPOZITIV/releases/download/latest/DOBROANDPOZITIV.dmg) и открой его двойным кликом.
2. Откроется окно со стрелкой. Перетащи значок приложения на папку **Applications**.
3. Открой приложение из «Программ». macOS скажет, что не может проверить разработчика: так она пишет про любое приложение без платного сертификата Apple. Нажми «Готово».
4. Зайди в **Системные настройки → Конфиденциальность и безопасность**, пролистай вниз и нажми **«Всё равно открыть»**, затем ещё раз «Открыть».
5. macOS спросит про **Универсальный доступ**. Нажми «Открыть Системные настройки» и включи переключатель у **DOBROANDPOZITIV**.

Обновление: скачай `.dmg` заново и повтори шаги. Если после обновления сообщения перестали оборачиваться, удали DOBROANDPOZITIV из списка «Универсальный доступ» кнопкой «−» и снова запусти приложение.

## Как пользоваться

- Значок `=👍=` в строке меню: яркий — включено, бледный — выключено.
- Включить и выключить: кликни по значку → «Добро и позитив».
- Чтобы приложение запускалось само при входе в систему, кликни по значку → «Запускать при входе».
- Не трогает: Shift+Enter (перенос строки), пустое поле, сообщение, которое уже стоит в `=…=`, поля поиска и паролей, терминалы и редакторы кода.

## Зачем «Универсальный доступ»

Без него macOS не даёт приложению видеть нажатие Enter. Приложение ничего не записывает и никуда не отправляет. Когда ты жмёшь Enter в поле ввода, оно вместо тебя нажимает `⌘↑`, `=`, `⌘↓`, `=` и Enter. Весь код в одном файле: [Sources/main.swift](Sources/main.swift).

## Удаление

Кликни по значку → «Выйти», удали DOBROANDPOZITIV из «Программ» и из списка «Универсальный доступ».

## Для разработки

- Сборка (нужны Xcode Command Line Tools, `xcode-select --install`): `./build.sh`, результат в `build/`.
- GitHub Actions собирает приложение на каждый пуш. Сборка из `main` попадает в релиз [latest](https://github.com/cybertatar/DOBROANDPOZITIV/releases/tag/latest).
- Иконка `Resources/AppIcon.png` собирается из фото: `python tools/make_icons.py фото.png` (нужны `rembg` и `pillow`).
- Фон окна установщика: `python tools/make_dmg_background.py`, раскладка окна — `dmg.py`.
